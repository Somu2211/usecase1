📊 Approach & Query

Query Code


WITH product_aggregates AS (
  SELECT 
    product_id,
    MAX(product_name) as product_name,
    SUM(total_quantity_sold) as total_units_sold,
    SUM(total_quantity_sold * avg_selling_price) / NULLIF(SUM(total_quantity_sold), 0) as weighted_avg_selling_price,
    MAX(standard_price) as standard_price,
    SUM(revenue_potential_score) as total_revenue_potential,
    SUM(transaction_count) as total_transactions
  FROM product_profit_analysis
  GROUP BY product_id
)
SELECT 
  product_id,
  product_name,
  total_units_sold,
  ROUND(weighted_avg_selling_price, 2) as avg_selling_price,
  standard_price,
  ROUND((weighted_avg_selling_price - standard_price) * total_units_sold, 2) as total_profit,
  ROUND(weighted_avg_selling_price - standard_price, 2) as profit_per_unit,
  ROUND(total_revenue_potential, 2) as revenue_potential_score,
  total_transactions
FROM product_aggregates
ORDER BY total_profit DESC

Query Description

Used SQL aggregation to GROUP BY product_id, summing total_quantity_sold and calculating weighted average selling prices across all transactions. Total profit was computed as (weighted_avg_selling_price - standard_price) × total_units_sold. Revenue potential scores were summed across all product records to identify products with the highest growth opportunity. Results were ordered by total_profit DESC to rank products by profitability, and separately by revenue_potential_score DESC to identify high-opportunity products.
